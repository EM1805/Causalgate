## Short description

CausalGate is a commercial software asset for AI-agent governance. It evaluates proposed agent actions using policy checks, causal evidence, authority scoring, and audit reports before returning PASS, REVIEW, or HARD_BLOCK.

## Product positioning

Most AI-agent guardrails focus on permissions, content, or security policy. CausalGate adds a causal-evidence gate for high-impact actions, asking whether the agent has enough causal authority to act.
