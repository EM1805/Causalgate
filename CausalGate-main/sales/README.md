# Sales Package

This folder contains materials for selling CausalGate as a complete software asset.

Recommended order of use:

1. Read `ASSET_SALE_CHECKLIST.md`.
2. Complete `IP_AND_LICENSE_DISCLOSURE.md`.
3. Deploy or screenshot `../site/index.html`.
4. Record the demo using `DEMO_VIDEO_SCRIPT.md`.
5. Publish a listing using `SIDEPROJECTORS_LISTING.md` or `FLIPPA_LISTING.md`.
6. Use `TRANSFER_GUIDE.md` during handover.

Suggested starting listing price is documented in `PRICING_SUGGESTION.md`.
