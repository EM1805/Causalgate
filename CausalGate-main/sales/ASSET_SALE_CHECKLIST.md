# Complete Asset Sale Checklist

## Before listing

- [ ] Run tests and create a clean release ZIP.
- [ ] Deploy `site/index.html` as landing page.
- [ ] Record the 60-second demo video using `sales/DEMO_VIDEO_SCRIPT.md`.
- [ ] Add screenshots from the demo reports.
- [ ] Decide asking price and floor price.
- [ ] Complete `sales/IP_AND_LICENSE_DISCLOSURE.md`.
- [ ] Prepare a short Loom/video walkthrough.

## Listing assets

- [ ] Title
- [ ] One-line summary
- [ ] Product screenshots
- [ ] Demo video
- [ ] Tech stack
- [ ] Included assets
- [ ] Known limitations
- [ ] Suggested roadmap
- [ ] Reason for selling

## Closing assets

- [ ] Asset purchase agreement
- [ ] IP assignment
- [ ] Source-code archive
- [ ] Repository transfer
- [ ] Domain transfer, if any
- [ ] Hosting transfer, if any
- [ ] Analytics transfer, if any
- [ ] Handover call

## After closing

- [ ] Buyer verifies repository and ZIP.
- [ ] Buyer runs setup commands.
- [ ] Seller answers agreed support questions during handover window.
