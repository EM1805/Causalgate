Causal firewall for AI agents

Stop agents from acting on weak causal claims.

CausalGate evaluates AI-agent actions before execution. It combines policy checks, causal evidence, authority scoring, and audit reports to return PASS, REVIEW, or HARD_BLOCK.

From proposed action to causal authority decision.

1. Agent actionTool call, recommendation, or workflow mutation.
2. Policy checkRisk level, environment, approval, rollback.
3. Evidence packageSCM, identification, estimation, diagnostics.
4. Authority scoreWeak, partial, or sufficient causal support.
5. Decision reportPASS, REVIEW, or HARD_BLOCK with audit trail.

Agent governance

Add a causal evidence boundary before high-impact tool calls or recommendations.

Causal authority

Score whether an action has identifiable, estimated, and diagnosed causal support.

Audit reports

Generate JSON and Markdown reports with reasons, next steps, and decision digest.

Built for CLI, API, and agent runtimes.

Use the Python API, run the FastAPI decision service, or integrate the CLI into agent workflows.

from causalgate import AgentCausalFirewall, CausalEvidence

firewall = AgentCausalFirewall()
evidence = CausalEvidence.from_file("evidence.json")

result = firewall.evaluate(
    action="increase_ad_spend",
    environment="production",
    risk_level="high",
    treatment="ad_spend",
    outcome="revenue",
    evidence=evidence,
    require_causal_evidence=True,
)

print(result.firewall_decision)
print(result.authority_score)
