## Description

CausalGate is a source-available commercial software project for AI-agent governance. It evaluates high-impact agent actions before execution and returns PASS, REVIEW, or HARD_BLOCK.

The core idea: agents should not take important actions based on weak causal claims. CausalGate combines risk policy, causal evidence packages, SCM/identification/estimation signals, authority scoring, and audit reports.
